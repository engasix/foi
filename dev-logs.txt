  What the validation agent does in sequence per record:

  1. Website liveness - HTTP GET fo_website → is the firm still active?
  2. IAPD cross-check - hit api.adviserinfo.sec.gov/search/firm/{CRD} → compare name, city,
  state → flag mismatches, correct where IAPD is authoritative (like Parkside's city)
  3. Content spot-check - scan scrape_cache content for principal_name → confirms LLM
  didn't hallucinate it
  4. Calculate confidence score - based on field completeness + validation results
  5. Write validation chain - one row per record in validation_chain table
  6. Advance status - enriched → validated

Confidence score calculation:
  Base score: field completeness (max 40)
